# sophirobot-v1

本仓库用于保存 Sophirobot V1 的 Arduino 控制代码。

## 文件说明

- `foldbot_a4988_quarter/foldbot_a4988_quarter.ino`：主控制程序
- `foldbot_a4988_quarter/web_ui.h`：网页控制界面相关代码

## 使用方法

1. 下载或克隆本仓库。
2. 使用 Arduino IDE 打开：
   `foldbot_a4988_quarter/foldbot_a4988_quarter.ino`
3. 在 Arduino IDE 中选择实际使用的开发板和串口。

## 开发环境

- IDE：Arduino IDE
- 开发板：ESP32-S3

## 注意事项

请在确认接线、电源和电机驱动配置后再给设备上电或进行运动测试。
